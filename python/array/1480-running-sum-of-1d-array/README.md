# Two Sum

- Categoria: Array
- Exercício: 1480
- Dificuldade: easy (verde)

# Link do Problema
https://leetcode.com/problems/running-sum-of-1d-array

# Minha explicação e entendimento:

O Objetivo do exercício era somar os números do array com seu antecessor.
em [1,1,1,1,1], por exemplo, a ideia era guardar o valor dentro de uma outra variável para ir acumulando a soma.
Assim, o primeiro 1 soma com 0 (soma = 0), o segundo soma com 1 (soma = 1 + 1 = 2) e cada resultado que é atribuido à soma, é guardado dentro de outra lista.
